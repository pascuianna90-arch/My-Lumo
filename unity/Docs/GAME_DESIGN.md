# My Lumo — Agreed Game Design

Visual target: polished warm 3D pet-life game at least as lively as the uploaded reference video, not a low-poly browser demo.

Lumo: exact approved white fluffy cat with huge blue eyes, facial reactions, blinking, ear/tail motion and contextual animations.

Core loop: user command → planner splits it into tasks → Lumo physically navigates → performs animation/interactions → persistent world state changes → next command continues from that state.

Example: "Put on the red cap and go to the city" → wardrobe → equip red cap → exit house → travel to city → stay there wearing the cap.

Needs: hunger, energy, happiness, hygiene, social.

Persistent possessions: clothing/hats, food, guitar, car, home upgrades, pets/animal friends.

Locations phase 1: bedroom, living room, kitchen, bathroom, wardrobe, yard. Phase 2: city, clothing shop, pizza restaurant, park, garage. Phase 3: beach, mountains, more social locations.
