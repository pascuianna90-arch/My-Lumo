# My Lumo – locked visual direction

The approved visual reference is the latest concept approved by the owner.

## Lumo
- White fluffy 3D cat.
- Very large blue eyes.
- Cute rounded proportions.
- Small neck medallion.
- Clothing and accessories can be equipped.
- Lumo must be a fully animated, rigged 3D character in the final game.

## Interface
- Dark navy My Lumo interface.
- Top status area for hunger, energy, hygiene, happiness, level and Lumo Coin.
- Rounded colorful action cards/buttons.
- Warm, polished, friendly 3D life-sim presentation.
- Small speech/thought bubble close to Lumo's head for emotional AI reactions.

## Interaction rule
The UI never replaces gameplay. When an action is selected, Lumo physically walks to the correct place and performs the animation in the 3D world.

## First playable milestone
Home scene with:
1. walking/navigation,
2. follow camera,
3. eating,
4. sleeping,
5. bathing,
6. dressing,
7. needs HUD,
8. level/XP,
9. emotional speech bubble.

The final visual quality depends on the approved rigged Lumo model, animations and detailed environment assets. Placeholder low-poly character art is not considered final.
