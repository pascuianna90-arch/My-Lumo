# My Lumo — First playable milestone

This milestone is the first version that should feel like the approved game rather than a technical demo.

## Locked look
- White fluffy Lumo with very large blue eyes.
- Dark navy My Lumo UI.
- Rounded, colorful action buttons and status panels.
- Warm polished 3D home.
- Emotional speech bubble beside Lumo's head.
- No low-poly replacement character is accepted as final art.

## Gameplay included
- Walk around the home.
- Third-person follow camera.
- Eat.
- Sleep.
- Bathe.
- Dress.
- Dance.
- Type a natural-language command.
- Needs: hunger, energy, hygiene, happiness, social.
- Level and XP.
- Lumo Coin.
- Daily goals.
- Persistent save.
- Emotional reaction bubble.
- Welcome-back reaction after the player has been away.

## Daily motivation
The first three daily goals are:
1. Feed Lumo.
2. Bathe Lumo.
3. Dress Lumo.

Each goal grants XP and Lumo Coin. More goals, achievements, weekly events and location unlocks can be added after this milestone is playable.

## Art dependency
The code is ready to drive the character, but the final visual result requires the approved rigged Lumo 3D model and its animation clips. The game must not ship with a generic substitute character.
